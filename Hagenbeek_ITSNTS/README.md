## Pipeline for taxonomic and functional characterization of microbiomes

The following folders contain the bioinformatic pipeline for characterizing both microbiome taxonomy and function from shotgun metagenome datasets. The Bash_scripts folder contains the general pipeline used to run the bioinformatic tools and process the shotgun data. 

The Data_analysis_python_scripts folder instead contains the python scripts used for analysing the visualizing the outputs of the various bioinformatic tools.
